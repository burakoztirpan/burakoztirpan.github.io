Nelibula Pipeline

Nelibula Pipeline is a private automation tool used by the owner of the Nelibula YouTube channel to manage the channel's own content.

It connects to the YouTube Data API and YouTube Analytics API with the channel owner's permission in order to:

  • upload and update videos on the Nelibula channel,
  • read the channel's own performance statistics.

The tool is not offered to the public and is used only for the Nelibula channel.
