Privacy Policy

Nelibula Pipeline · Last updated: November 3, 2026

Nelibula Pipeline ("the app") is a private automation tool used only by the owner of the Nelibula YouTube channel. This policy explains what data the app accesses and how it is handled.

Data the app accesses

With the channel owner's explicit consent through Google sign-in, the app uses the YouTube Data API and YouTube Analytics API to access:

  • the channel's videos, playlists and video metadata,
  • the channel's analytics and performance reports.

How the data is used

The data is used only to upload and manage videos on the Nelibula channel and to report on the channel's own performance. It is not used for advertising, profiling or any other purpose.

Storage and sharing

OAuth tokens and retrieved data are stored only in the channel owner's self-hosted automation environment. The data is not sold, rented or shared with third parties.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google security settings page. Stored tokens are deleted when access is revoked or when the app is no longer used.
